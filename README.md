# Inventário 68

Sistema web de gerenciamento do laboratório 68 de eletrônica do IFRN Campus Apodi

## Descrição

Aplicação web que tem por objetivo auxiliar na gestão do laboratório, permitindo a criação de um inventário dos componentes e itens e também que os alunos criem projetos para divulgá-los e informar os componentes que estão sendo usados, assim permitindo os administradores terem controle do que está sendo usado e desenvolvido.
